## Implemented Algorithms

- **Rooms** – random room placement connected by corridors
- **BSP** – Binary Space Partitioning using recursive space subdivision
- **Drunken Walk** – random walk algorithm with a target map coverage of 50%
- **Cellular** – cellular automata for generating cave-like structures
- **Maze** – maze generation using the Recursive Backtracker (DFS) algorithm

## Requirements

- [Godot Engine 4.6.X](https://godotengine.org/download/) (optional, only required if you want to run the project from source)
- Python 3.10+ (optional, only required for result analysis)

## Running the Application

### Option A – Prebuilt Executables (Recommended)

Precompiled executables are available in the `executables/` directory:

- **macOS** – open `ProceduralGenerationProject_MacOS.dmg` and launch the application.
- **Windows** – run `ProceduralGenerationProject_WIN.exe`.

> **Note:** Benchmark results (`results.csv`) are saved to the application's user data directory:
>
> - **macOS:** `~/Library/Application Support/Godot/app_userdata/<project_name>/results.csv`
> - **Windows:** `C:\Users\<username>\AppData\Roaming\Godot\app_userdata\<project_name>\results.csv`
>
> The exact file path is displayed in the status bar once the benchmark has finished.

### Option B – Running from Source in Godot

1. Clone the repository:
   ```bash
   git clone https://github.com/Jim-23/ProceduralGenerationBP.git
   ```

2. Open Godot Engine and select **Import**.
3. Choose the `project.godot` file located in the `proceduralgenerationproject/` directory.
4. Run the project.

## Controls

- **W A S D** – move the player
- **Mouse Wheel** – zoom in / zoom out
- **Right Mouse Button** – freely pan the camera
- **R** or any movement key – refocus the camera on the player
- **Generate** – generate a dungeon using the selected algorithm and map dimensions
- **Benchmark** – run automated benchmarks for all algorithms across five map sizes (each configuration is executed 10 times by default, and results are saved to `results.csv`). The number of iterations can be adjusted by choosing number in `Runs`.
- **Seed** + checkbox – use a custom numeric seed to reproduce results. The checkbox must be enabled for the custom seed to take effect.

## Result Analysis

After running a benchmark, plots can be generated using the `result_analyser.py` script:

```bash
pip install -r requirements.txt
python result_analyser.py
```

Generated plots will be saved in the `plots/` directory.

## Project Structure

```text
dungeons/algorithms/   - dungeon generation algorithms
scripts/               - game logic (main, player, coin, camera_2D)
scenes/                - Godot scenes
assets/                - graphical assets
plots/                 - generated analysis plots
result_analyser.py     - Python script for result analysis
results.csv            - raw benchmark data
result_summary.csv     - processed benchmark summary (generated by result_analyser.py)
requirements.txt       - Python dependencies required by result_analyser.py
```

## Ovládání

- **W A S D** - pohyb hráče
- **Kolečko myši** - přiblížení / oddálení
- **Pravé tlačítko myši** - pohybování po mapě nezávisle na hráči
- **R** nebo klávesy pro pohyb hráře - focus zpět na hráče
- **Generate** - vygeneruje mapu na základě zvoleného algoritmu a rozměrů
- **Benchmark** - spustí automatizované měření všech algoritmů na pěti velikostech map (každou kombinaci 10x, výsledky se uloží do `results.csv`) - počet průchodů lze nastavit
- **Seed** a checkbox - lze nastavit vlastní číselný seed pro reprodukovatelnsot výsledků, musí se zaškrnout checkbox, aby byl seed aplikován


## Analýza výsledků

```
pip install -r requirements.txt
python result_analyser.py
```

Grafy budou uloženy do složky `plots/`.
